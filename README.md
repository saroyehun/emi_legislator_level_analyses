# Epistemic orientation predicts legislative effectiveness among members of the US Congress

This repository contains the co[de used for the analysis and results reported in the manuscript **[Epistemic orientation predicts legislative effectiveness among members of the US Congress](https://doi.org/10.48550/arXiv.2609.11865)**

## Notes
* We developed the codes using Python (3.11.6) and R (4.3.1) on Ubuntu 22.04.
* The data required to reproduce the plots and statistical analyses are available in the `data` directory, with corresponding scripts in the `code` directory.
